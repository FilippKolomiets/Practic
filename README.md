# Dataset Builder

Извлечение смысловых фрагментов из русскоязычных научных статей в формате PDF по заданным корням слов. Для поиска используется локальная языковая модель через [Ollama](https://ollama.com), а для разбивки текста на предложения – библиотека [Natasha](https://github.com/natasha/natasha). Результат сохраняется в файл `dataset.jsonl` с указанием названия статьи, авторов и найденных отрывков.

## Что делает скрипт

- Находит все PDF-файлы в папке `assets`.
- Извлекает текст, разбивает его на блоки.
- Ищет блоки, содержащие заданные корни слов (например, `"существ"`, `"единствен"`).
- Объединяет соседние блоки в осмысленный фрагмент (предыдущий, текущий, следующий).
- Определяет название статьи и авторов по тексту первой страницы с помощью модели `qwen2.5:7b`.
- Очищает текст, разбивает на предложения и записывает результат в `dataset.jsonl`.

## Требования

- **Python 3.8+** (убедитесь, что он установлен: `python --version`)
- **Ollama** – для работы языковой модели ([инструкция по установке ниже](#установка-ollama))
- Около **5 ГБ свободного места** (для модели Ollama и данных Natasha)
- Подключение к интернету для первого запуска Natasha (скачивание моделей) и загрузки LLM

## Быстрый старт

1. Скачайте ZIP-архив с кодом и распакуйте его в любую папку.
2. Откройте терминал (командную строку) в этой папке.
3. Установите зависимости Python:
   ```bash
   pip install -r requirements.txt
   
   Установите и запустите Ollama (см. инструкцию).

Загрузите модель:
ollama pull qwen2.5:7b
Поместите PDF-файлы в папку assets (если её нет – создайте).

При необходимости измените список корней в конце файла dataset_builder.py (переменная roots).

Запустите скрипт
python dataset_builder.py
Результат появится в файле dataset.jsonl в той же папке.
